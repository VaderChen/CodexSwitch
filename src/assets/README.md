# App 圖示

- `CodexSwitch.png`：內建 imagegen 產生的透明背景原圖。
- `CodexSwitch.icns`：以 macOS `sips` 縮放、`iconutil` 封裝，包含 16、32、128、256、512 點及各自的 2 倍解析度。
- `build.command` 會複製 ICNS 至 App Resources，並設定 `CFBundleIconFile`。

## 生成提示詞

用途：CodexSwitch 的 macOS App 圖示。製作單一正方形 1024×1024 圖示，主體是一個精緻、簡潔、容易辨識的電燈翹板開關，開啟狀態，白色陶瓷開關配淡紫色圓角方形底板，呼應應用程式既有淡紫色介面。正面視角，略帶立體厚度與柔和陰影，小面積綠色指示燈，主體置中，縮小仍清楚。整體為高品質 macOS 桌面圖示，外緣保留約 8% 透明留白，圓角方形之外是真正透明背景。無文字、無字母、無浮水印、無額外物件。
