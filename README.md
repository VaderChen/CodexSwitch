# CodexSwitch

CodexSwitch 是 macOS 上的 Codex 帳號管理工具，讓你在多個 Codex 帳號之間快速切換。

## 功能與特色

- 使用瀏覽器完成 Codex 帳號登入
- 管理多個 Codex 帳號
- 一鍵套用指定帳號
- 套用前自動處理已開啟的 Codex App
- 匯入與匯出帳號列表
- 偵測目前使用中的 Codex 帳號
- 顯示帳號連結狀態與更新時間
- 顯示帳號剩餘用量
- 支援用量重置操作
- 明亮、簡潔、緊湊的介面
- 支援 macOS 常用快捷鍵
- 支援 `⌘Q` 結束程式
- 視窗尺寸會自動記住
- 套用完成後清楚提示下一步

## 快速開始

雙擊 `run.command` 即可啟動 CodexSwitch。第一次使用時，按下「開啟瀏覽器登入」完成帳號登入。

在帳號列表中按「套用」，即可切換到指定帳號。CodexSwitch 會先確認 Codex App 狀態，完成後啟動對應帳號。
